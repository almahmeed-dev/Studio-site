Make your first design

  1. Create a project and choose Photos, Files, Camera or finger drawing. Camera access is optional.
  2. Review the source and confirm its intended physical dimensions. A photo's DPI, zoom and screen size do not establish real size.
  3. Preview cleanup, then trace filled-region boundaries. Inspect holes and small details before accepting.
  4. Refine paths and layers. In stencil mode, review retained islands and add bridges when needed.
  5. Choose the included visible layers and artwork or stencil output mode, resolve preflight issues, then generate and inspect the actual saved file. Export selection does not change the project’s layer visibility.

Print at the intended size

Review the PDF page plan before generating it. Actual-size and tiled output use the chosen physical dimensions; scaled overview is a separate mode that can reduce or enlarge artwork. Select 100% / Actual Size in the print dialog and measure the 100 mm calibration mark on actual-size pages. Print-dialog Fit to page changes print scale. Gray assembly guides are not cut lines. Printer and receiving-app behavior needs its own check.

Display units and physical size

Changing millimeters or inches changes the displayed measurements without rescaling artwork. Screen zoom and folding also leave physical geometry unchanged. Use the explicit design-size operation when you intend to scale the artwork.

Keep an editable backup

Library → Backup lets you select projects and review an .inkcut archive before sharing. Library → Restore backup → Choose .inkcut backup validates selected bytes before a reviewed restore. Review duplicate-origin choices and keep a separate new project.

Editable backups include normalized source artwork, private notes, geometry and saved versions. SVG/PDF/PNG exports are separate public outputs and cannot reconstruct edit history.

If something fails

Keep existing projects and inspect the reported recovery options. Check storage before retrying. Do not uninstall as the first troubleshooting step: removing the app may remove local projects. Canceling a share or Files sheet does not mean a file was saved.

Source and file limits

Raster intake supports JPEG, PNG and HEIC/HEIF, up to 20 MiB encoded and 40 megapixels decoded. Normalized artwork is bounded to 4,096 pixels on its long edge. The same technical limits apply to every purchaser.

Purchase and redownload

InkCut is preparing for release as a paid download with all v1 features included. There is no in-app upgrade or restore-purchases action. Redownload availability is controlled by Apple and the purchasing Apple Account; recovering artwork requires your project data or editable backup.
